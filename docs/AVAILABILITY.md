# Code and data availability

The repository contains implementations of wavelength-indexed convolution,
O-VGG classification, and optical style transfer:

`https://github.com/Liuwc01/Native-optical-computing-with-POWA`

Author-generated spectra, waveform exports, numerical summaries, training logs
and a runnable O-VGG sample are included in the same repository. Data packages
provide machine-readable manifests and SHA-256 checksums.

CIFAR-10, CIFAR-100 and style/content image datasets are third-party resources
and are not redistributed. Their official or original distribution channels
should be used when running the corresponding workflows.
