# Numerical data packages

This directory contains author-generated experimental and numerical data used
by the repository examples and plotting scripts.

| Package | Contents | Formats |
|---|---|---|
| `fig2c_figS1_wpu_broadband_response/` | Eight-port broadband WPU response | MAT, JSON |
| `device_and_system/` | WPU and microring spectra, input sequences and measured waveforms | FIG, MAT, CSV, TXT, JSON |
| `fig3_ovgg/` | O-VGG accuracy and parameter-count summaries | CSV, MATLAB, JSON |
| `fig4_style_transfer/` | Style-transfer logs, loss curves, fusion weights and parameter counts | TXT, CSV, JSON |

Each package documents its variables and processing relationships in a README
and `manifest.json`. File integrity can be checked with `SHA256SUMS.txt`.

Third-party image datasets are not redistributed.
