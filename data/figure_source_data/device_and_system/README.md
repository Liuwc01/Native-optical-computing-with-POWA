# Device and system data

This directory groups author-generated spectral and time-domain measurements.

| Package | Contents |
|---|---|
| `fig2c_microring_response/` | Full and sampled microring spectral responses |
| `fig2c_figS1_wpu_single_port_response/` | Single-port WPU response with an explicit wavelength axis |
| `fig2f_figS8_figS11_high_speed_waveforms/` | Ideal input sequence, oscilloscope export and channel extract |

Numeric values are preserved in their source representation. Each package
provides a machine-readable `manifest.json` and SHA-256 checksums.
