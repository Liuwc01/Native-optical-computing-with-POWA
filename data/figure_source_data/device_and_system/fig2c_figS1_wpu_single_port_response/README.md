# WPU single-port spectral response

`wpu_output_port7_response_with_wavelength_axis.mat` is a MATLAB v7.3/HDF5
file containing `xiangying2` with shape 2 x 2,400,001:

- row 1: wavelength in nm, spanning 1500-1620 nm;
- row 2: output-port 7 response in dB.

The response row is identical to output port 7 in
`data/source/wpu_spectrum_1500_1620_db.mat`. Numeric values were not modified.
See `manifest.json` for metadata and `SHA256SUMS.txt` for integrity checks.
