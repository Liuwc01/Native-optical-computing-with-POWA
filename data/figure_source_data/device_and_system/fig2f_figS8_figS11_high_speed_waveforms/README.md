# High-speed waveform data

| File | Format and contents |
|---|---|
| `ideal_input_waveform_500MHz_AWG_10GSa.txt` | Headerless one-column input sequence; 3,870,020 values |
| `experimental_oscilloscope_export_3col.csv` | Headerless three-column oscilloscope export; 1,048,576 rows |
| `experimental_channel3_extract.csv` | Third column of the oscilloscope export; 1,048,576 values |

The source files do not encode column names or units. Numeric values are
preserved without transformation. See `manifest.json` for ranges and shapes
and `SHA256SUMS.txt` for integrity checks.
